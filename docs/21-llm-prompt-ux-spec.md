## 一、现行形态

18 项一屏放得下，面板只剩两件事：**顶部一行只读状态** + **18 项按语义排好**。
折叠、分组、chip、预设按钮、通道开关都是 39 项时代的补丁，合并后一并删掉（见 `docs/20` §九）。

判据不在这页重抄，在闸里：`tools/ui_llm_panel.mjs`（19 格存档 / 18 行全显 / 级联 9 档与 1 档 /
缺项提示 / 存盘重开逐位一致 / 280px 不溢出）、`tools/check_frontend.py`（F2–F11）、
`tests/test_llm_subpackage.py`。

## 二、仍然生效的判据

| 编号 | 判据 | 现状 |
|---|---|---|
| F-1 | **PE 可用** ＝ 合取五条：代码分支能跑 / 有可拖示例 / README 步骤 / README 许可边界 / report 能确认 | 缺「可拖示例」⇒ 仍只许写「条件性可用」 |
| F-2 | **控件搭配妥当**：任一组合下「可见集」与「生效集」的差为空，或 inert 有显式标注；切 `task` 后焦点不丢 | 面板已无按钮组合，只剩参数行；此判据对**下次再加按钮**仍生效（`MODE_SPEC` + `plan()`） |
| F-3 | **不强绑定 MOSS**：编译层通用 + 至少一条非 MOSS 示例 | 编译层成立；示例未达成 |
| F-4 | 分层体验 | 不实施（见下） |

**证伪线**：出现「声明覆盖面大于实现」的承诺 —— 文档说做了、代码没做 —— 即回滚对应的改动，
不补一句解释。

## 三、明确不做

- **分层体验**：2026-11-04 取消。不新增「新手 / 专家」模式旋钮 —— 加一个开关等于把实现分支
  暴露成旋钮；分层改由默认路径、文档、示例与 report 承载。
- **nodeDef 自定义键透传**：宿主行为未用探针确认，不赌。
- **report 首行固定前缀**：弱约定，改类型会动存档契约。
- **新增状态通道**：`report` 保持 STRING，执行前状态一律由前端自己算。
