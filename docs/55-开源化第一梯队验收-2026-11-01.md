### 1.2 G7 第二轮（20 图前后对比 + 60 图扩样）

同 20 图 gold set、同 seed/参数、两模型复跑（管线变更包：SYSTEM sha 431b→740b + 类型闸 +
maxItems 同时变，**不归因单一因素**）：

| 指标 | A-4B | B-9B |
|---|---|---|
| 材质绑定覆盖率 | 40%（18/45）→ **96%（94/98）** | 44%（12/27）→ **100%（46/46）** |
| 物体编年龄幻觉 | 12 → **0** | 1 → **0** |
| 跑批失败率 | 15% → **5%** | 5% → **0%** |
| 文字两遍互证率 | 24% → **50%** | 62% → **71%** |

- **A 臂五类全表下降 = 分母污染**：3 张 maxItems 截断图占颜色分母 62%、方位 54%、数量 77%；
  非循环 17 图上 A 为颜色 88% / 方位 94% / 数量 100%，**没有回归**。归因审计：颜色 93%、
  方位 94%、数量 100% 属分母口径；渲染层 3 例（4%）；判据层 9 例（6%）；模型层 0 例。
- **材质提升不是分母把戏**：绝对 bound A 5.2×、B 3.8×；A 剩 4 条为人物分支不渲染 material 的
  c 案残余（docs/42 reopen 条件）。
- **60 图扩样**：gold set 冻结（旧 20 张 byte-identical），A 55/60 成功、B 60/60；材质 A 98%、
  B 99%；非截断图上两臂接近（颜色 91/85、方位 91/91、文字 95/92、数量 82/93）。A 5 次失败
  全为 `finish=length` JSON 未闭合（多人宽景/满版文字），B 在同批图 0 失败（样本小，不作显著性）。
- **耗时不可比**：跑批期间本机 GPU 有外部游戏争用（快照 `gpu-contention.json`），报告不产出性能结论。
- 证据：`docs/G7-反推质量-第二轮.md`、`out/g7/round2/{compare-20,binding20,binding60,…}`。

## 6. 未验证 / 边界（诚实清单）

1. **所有「效果」结论仍是代理论据**：G7 目检/判读是 **AI 代理**（非人类）；双盲判读证据等级 B
   （同模型双读）；人类判读包已备好但未做。
2. **κ<0.6 ⇒ 第一轮不能比较模型优劣**；不可判口径未统一（下一轮需判例 + 小样预校准）。
3. **自动分 ρ=0.3162 <0.5** ⇒ 本轮任何自动分不得进 README；校准只覆盖材质类 10 格。
4. **A 臂全表数字在修掉静默截断前不可引用**（10 张截断图灌大分母）；60 图无第一轮基线，
   横向比较只看非截断子表。
5. **GH runner 未本机验证**（runner 镜像/windows/两 host tag 克隆/pip 解析）。
6. **节点 caption 质量未真机跑**（护栏接线是单测 + 桩服务端验证；零 GPU）。
7. **Registry `Flagged` 的具体扫描 issues 查不到**（公开 API 无清单，只进私有频道）；
   Manager 在非 loopback/strong 安全级下的行为未真机验证。
8. **T12（H3 Rewriter LoRA）仍暂缓**：27B 已放弃，8B 契约方案待拍板（docs/35）。
9. 耗时记录不可比（外部 GPU 争用），本报告不产出任何性能结论。
