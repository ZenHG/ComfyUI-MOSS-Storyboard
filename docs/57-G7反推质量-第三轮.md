5. B-9B 几乎不变（干净子集 n=18：颜色 82%→86%，材质/方位 100%→100%，文字 76%→76%），
   失败 1/20 是**解析前截断**（img07 JSON 未闭合，重复形态但没走到 `coerce_ir` 闸）。
6. 没有人类判读，本轮**不写「质量更好」**；只写：失败可见性变好、分母口径修正、

### 3.2 「排除循环相关图」子表（干净子集，自动派生 / 口径敏感）

**dirty 定义（从产物自动派生，脚本 `out/g7/round3/_clean_subset.py`，无硬编码 id）**：

```
dirty(model) = round2_capped_proxy ∪ round3_failed ∪ round3_capped ∪ round3_merged
  round2_capped_proxy : round2 JSON report.entity_count == 40（MAX_ENTITIES）
                        ——proxy：round2 跑在 M1a-3 之前，report.capped 字段不存在；
                        只能用「实体数恰好 40」推断被 maxItems 截断（不是字面 capped）
```

## 6. 未验证 / 边界

1. **干净子集口径敏感**（§3.2）：strict 与 proxy 方向相反，n=12–13，且排除本身有选择偏差
   ⇒ 「正常图质量变化」本轮判 **未验证/样本不足**，不写「没变」也不写「变好」。
2. **round2 的 capped 只能用 proxy**：`entity_count==40`（M1a-3 之前无 `report.capped` 字段），
   与 round3 的字面 capped 不是同一观测；跨轮比较必须按本文定义读。
3. **50% 重复阈值是工程判断**（`docs/56` §2.3），没有真机频率分布校准；对「恰好 40 条
   但有 18 条重复（45%）」的图会合并而非失败——这类图的处理质量未目检。
4. **B 的「解析前截断」未被循环闸覆盖**（img07 本轮就是）：重复循环可能在 JSON 闭合前
   耗尽 max_tokens，只能按 JSON 截断失败记录。
5. **节点 caption 路径未改**（`docs/56` §6）：本轮只验证 smith 反推路径。
6. **无人类判读**：全部结论是机检 + 失败计数；「质量」类表述本轮一律不写。
7. 单臂单次运行，无重复采样/方差估计；20 图样本，失败率置信区间未算。
8. capped/合并成功的 A img13/img19/img08/img10、B img12 未逐条目检（只确认 report 出声）。
9. §5 的 util 91% / free ~2.4 GiB 是人工观察，未存证。
