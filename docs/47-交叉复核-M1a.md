## 1. 逐条对账

### 1.1 「36 份成功记录、110 个 character、58 个命中（53%）」

从 `out/g7/json/{A-4B,B-9B}/*.json` 的**落盘 IR** 重算（规则照任务书：`kind=character` ∧
无 gender/hair/skin/face/expression ∧ 有 material/color/build/detail 之一）：

| | character | 命中 | 占比 |
|---|---|---|---|
| A-4B | 62 | 34 | 55% |
| B-9B | 48 | 24 | 50% |
| 合计 | **110** | **58** | **52.7%（文档写 53%，四舍五入正确）** |

- 成功记录：40 个落盘 JSON 里 `ok=true` 的 **36** 个（A 17 / B 19），失败 4 个（A img07/img10/img14、B img07），与声明一致；
- 实体总数 175（110 character + 其余），与 G7 报告 §4.4 的 101+74=175 一致。

**判定：PASS（逐数对上）。**

### 1.2 「58 个命中全部带 `descriptors.material`」→ 实际 57/58

- 58 个命中里带 material 的 = **57**；
- 唯一的例外：**A-4B · img08 · e8**，`kind=character`、`label="light"`、
  `descriptors={"color": "blue and red neon lights outside", "position": "blurred..."}` —
  只有 color 字段、没有 material，所以命中规则但没有 material。
- 该实体被降级仍是对的（它确实不是人），只是「命中⇒带 material」不成立。

**判定：FAIL（数字）。** 建议改成「58 个命中里 57 个带 material；另 1 个只有 color」。
对结论无影响（§188「58 个实体可被降级」仍然正确）。

### 1.3 「b 已覆盖 58/59 的材质损失，剩 1 例」→ 实际 57/58，剩 1 例

独立重算三组数（全部来自落盘 IR）：

- `kind=character` 且 `descriptors.material` 非空：**58** 个；
- 其中被类型闸规则覆盖：**57** 个；
- 剩余：**1** 个 = A-4B · img18 · e1 `bronze eagle statue`
  （`hair/skin/face/expression` + `material=bronze` + `age=50` → 有任一人物字段，规则不降级）。

所以：

- 「character 且带 material」的分母是 **58**（不是 59），覆盖 **57**（不是 58）；
- docs/42 §1.4 原文「共 58 个，全部命中 b 的降级规则；剩下 1 例…」**内部自相矛盾**
  （58 个全命中 ⇔ 没有剩余；实际是 57 命中 + 1 剩余）；
- 结论（不做 c 案、残余 1 例）**不受影响**；但 g7-gold 的前后对比若引用这个数字，
  必须写 **57/58（98.3%）** 而不是 58/59（98.3% 的百分比恰好一样，但分母/分子都错）。

**判定：FAIL（数字 + 一处自相矛盾）。**

### 1.4 「现有 57 个夹具实体里 0 例 character+material」

- `tests/fixtures/smith/*.ir.json`（4 份真机 IR）：实体 **18**、character **7**、
  character 带 material/color/build/detail 的 **0**；
- 放宽到全仓非 `out/` 的 JSON（含 `moss_llm/smith/examples`）：含 entities 的 JSON 9 个、实体合计 **29**、
  仍 **0** 例 character+object 字段；
- `tests/test_caption_quality.py` 自带构造实体 9 条，与 57 也对不上。

**结论（0 例）PASS**：无论用哪个可界定的夹具口径都是 0 例，所以「c 案收益测不到」成立。
**但「57 个夹具实体」这个分母无法复现**——docs/42 正文并没有写 57（只写
`tests/fixtures/smith/*.ir.json`，该口径是 18 个实体）；57 应是任务转述时的误记。
建议在报告里写「smith 夹具 18 个实体（7 character）里 0 例」，去掉 57。
