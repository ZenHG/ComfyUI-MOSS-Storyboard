## 0. 一句话

**下一步不是加模型、加语料，而是把「反推 → 扩写 → 洗图 → 再反推」接成可判闭环**，
先用**机检事实保全 + 多 seed 噪声线**建立可信分母，再谈「哪个档更好 / 怎么调」。

## 2. 现状依据（为什么这样定）

1. **洗图第一轮（docs/31）自己写明的局限**：4 张源图、2 后端、代理 triage **未校准**、
   无置信区间、Qwen 未跑通；下一步清单第一条虽是 VQAScore/人类偏好，但**当前连采样方差都没有**，
   直接做偏好校准会把噪声当结论。
2. **反推侧已有可靠的上游**：G7 60 图 gold set + 事实判读 κ=0.8555（docs/58/59）；
   但 binding 机检分与判读排序 ρ=−0.0301（docs/59），**不能当质量分**——所以本轮不用它做判据。
3. **扩写侧只有判据与单测（docs/26）**，没有大样本事实保持数字；这是最便宜、最该先补的机检指标。
4. **Qwen-Image 2.1 权重的现实**：本机 `diffusion_models` 只有 Qwen-Image-Flash-Q4_K_M；
   `wash_benchmark.py` 已如实标注「Flash 不是 2.1，结论不外推」。

## 3. 任务分解（Round 1）

### P0-1 · 扩写事实保持（CPU，零 GPU）

- 输入：G7 60 图两臂 caption（A-4B 55 成功 + B-9B 60；失败单元单列）对应的 IR / caption 文本。
- 处理：扩写三拆（补全 / 翻译 / 改写，开关可关；**目标方言只 `moss-image`**）；
  对每份产出用 `roundtrip.diff` / expand verify 与输入事实集合对比。
- 指标：`lost=0` 的单元比例、lost 明细（哪些事实、哪类）、extra 单列；分母逐格给出。
- 产出：事实保持表 + 失败清单；发现「扩写会编事实」时只记录，不在本轮修判据。
- 成本：约半天（纯 CPU）。

### P0-2 · 洗图 3-seed 方差线（GPU，MOSS 用户指定档）

- 输入：G7 20 图 gold set（4 类各 5，复用 G7 第一轮源图）。
- 生成：**用户指定档**（`MOSS-Image-SFT-Q4_K_S` + `8-steps-dmd2-lora` + `moss-te-heretic` TE，
  8 步 / cfg 1.0 / euler / simple / 1024²），每源图 **3 seeds**（同 prompt、同分辨率、同采样参数）。
- 指标：现有代理 triage 分的**跨 seed 均值/极差**（明确 `calibrated=false`，只作「漂移」测量，
  不作质量结论）；同时记录每张生成耗时/失败。
- 成本：Lead 真机实测（2026-11-01）：首图 94.0 s（含加载），热态 **12.4 / 12.3 / 13.0 s**（1024²，
  3 seeds 同一 prompt）；显存 used ≈ 8.0–8.4 GB、free ≈ 3.6–4.0 GB（宿主常驻）。
  20 图 × 3 seed ≈ **13–15 分钟** GPU（串行）。

### P0-3 · roundtrip 事实保全（GPU + 反推）

- 链路：源图 → 反推 caption（复用现有 smith 反推路径，A-4B 一臂即可）→ 扩写（moss 方言）
  → 洗图（P0-2 同配置，取 1 seed）→ **再反推** → IR 事实集合 diff。
- 指标：lost / extra / 分母；文字实体单独统计（生成图文字保真另列，OCR 留到第二轮）。
- 产出：20 图 roundtrip 保全率表；明确「captions 是模型产出，不是人类真值」。
- 成本：反推 20 图 × 2 次 ≈ 5–10 分钟 + 洗图复用 P0-2 产物。

### P0-4 · 工具与测试（CPU）

- `tools/wash_benchmark.py`：加 `--seeds N`（同源图多 seed）、`--roundtrip`（反推 A → 扩写 →
  洗图 → 反推 B 的事实 diff 报告）；保持 `--seed` 覆盖语义不变。
- `tests/test_wash_benchmark.py`：新增离线测试（多 seed 的确定性 workflow 构造、roundtrip
  diff 的纯函数、缺后端时的降级），**不跑 GPU**。
- CI 计数同步（CONTRIBUTING / ci.yml 注释）。

### P0-5 · 文档

- 结果：`docs/68-洗图闭环-第一轮.md`（数字 + 分母 + 未验证项 + 复现命令）。

## 4. 验收判据（写死，避免「看起来可以」）

1. **扩写事实保持**：每单元给出 `lost` 明细；`lost=0` 的比例 + 分母可复核；不存在「没跑却算通过」。
2. **3-seed 方差**：20 图 × 3 seed 全部落盘（失败要写明原因，不跳过）；报告 seed 极差中位数。
3. **roundtrip**：20 图链路逐步落盘（每个阶段文件 + sha），事实 diff 可复跑；不能只报一个总分。
4. **工具**：`python tests/test_wash_benchmark.py` 全绿（离线）；`--check` / `--plan` 不回归。
5. **诚实边界**：本轮不写「MOSS 比谁好」「扩写提升了质量」「洗图分可信」；只写「保全率 / 方差 /
   失败率」；代理分仍标 `calibrated=false`。
6. **不冒充**：Qwen 段落只写「用户下载后补入 Round 2」；H3 段落只写「冻结」。

## 6. 风险 / 未验证（计划阶段就写清）

1. **MOSS-Image 采样档差异**：4 步 turbo 与 50 步 SFT 的视觉差异可能大于 seed 方差；本轮只把
   4 步 turbo 当主档，SFT 档可选，不混在一起比较。
2. **代理 triage 分未校准**：只用于「漂移」测量；不得当质量结论，不得进 README。
3. **扩写「事实保持」依赖 IR 事实抽取**：抽取器本身有盲区（文字/材质），lost=0 不等于人读无变化。
4. **roundtrip 的再反推受反推质量影响**（A-4B 单臂、60 图事实 κ 可用但非人类真值）；若再反推
   失败按失败单列，不剔除不出声。
5. **Qwen-Image 2.1 未到位**：本轮不产出 Qwen 任何数字；用户下载后需重新确认权重/加载器/显存。
6. **宿主环境**：本轮依赖宿主 8188 与原生 MOSS 节点；若宿主不可用，如实记录 blocker，不跳过。
