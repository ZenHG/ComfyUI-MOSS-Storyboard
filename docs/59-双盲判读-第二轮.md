## 0. 一页结论

| 项 | 数值 | 判定 |
|---|---|---|
| 判读单元 | **115**（A-4B 55 / B-9B 60；A-4B 5 个失败单元单列不判） | — |
| 事实 claim | **458**（A-4B 220 / B-9B 238） | — |
| **事实一致性 κ** | **0.8555**（n=458；Po 0.9956 / Pe 0.9698） | **≥0.60（事实维度通过）** |
| — 分模型 κ | A-4B **1.0000**（n=220）/ B-9B **0.7969**（n=238） | 均 ≥0.60 |
| 图级幻觉 κ | **0.1722**（n=115） | **<0.60（未校准）** |
| **协议门槛（min κ）** | **0.1722 < 0.60** | **三档结论 = 样本不足（判据不足）** |
| 事实准确率（描述性） | A-4B **99.1%**（218/220，CI [96.7, 99.8]）；B-9B **99.2%**（232/234，CI [96.9, 99.8]） | Fisher p=1.0；**不得当模型结论** |
| 评分校准（同版 binding60） | **ρ = −0.0301**（n=115；A −0.1615 / B 0.0941） | **该分不应进 README** |
| 证据等级 | **AI 双读（非人类）；两名判读者同一底层模型** | 独立性弱于「不同模型双读」 |

**一句话**：v2 判据把**事实维度**的一致性从第一轮的 κ=0.4129 拉到 **0.8555**，
`unverifiable` 从 49/18 收敛到 2/4——这是本轮真正的协议成果；但**图级幻觉维度仍未校准**
（κ=0.1722），按 docs/43「取所有 κ 最小值」的门槛，**整体结论只能是「样本不足」**：
两臂事实准确率 99.1% / 99.2% 只能描述，**不能下「谁更好」或「无显著差异」的结论**。
自动分（binding 覆盖率）与判读排序**没有关系**（ρ≈0），**不得进 README**。

## 2. 一致性（协议门槛）

`merge`（`--manifest 60img/manifest.json`）输出：

| 维度 | n | κ | 原始一致率 Po | 期望一致率 Pe | 门槛 |
|---|---|---|---|---|---|
| **事实 verdict（三分类）** | 458 | **0.8555** | 0.9956 | 0.9698 | **过** |
| — A-4B | 220 | 1.0000 | 1.0000 | 0.9820 | 过 |
| — B-9B | 238 | 0.7969 | 0.9916 | 0.9586 | 过 |
| **整图幻觉（二分类）** | 115 | **0.1722** | 0.7913 | 0.7479 | **不过** |
| **min κ（协议门槛）** | — | **0.1722** | — | — | **<0.60 → 样本不足** |

**与第一轮对比**：事实 κ **0.4129 → 0.8555**；分模型最小 κ 0.3881 → 0.7969；
`unverifiable` 分歧 **49/18 → 2/4**。v2 的「只有图中没有视觉证据才可判不可判 + 年龄年龄段 +
文字逐字 + 近似边界」确实把事实判读收敛了。

**幻觉维度为什么仍低**：115 个单元每单元只有 1 个 present/absent 值，且判读者对
「模板措辞（如 same figure appears again）算不算幻觉」「文字专线占位串算不算」边界不同；
κ=0.1722 说明**这一维度不可用**。按 docs/43 §4.2「取所有 κ 最小值」，整体仍只能判
**样本不足（判据不足）**——即使事实维度已过。若要把幻觉纳入门禁，需要另做一轮带判例的幻觉校准。

## 4. 事实准确率（描述性；不得当模型结论）

合并真值只取「两人 verdict 相同」的 claim（2 条分歧 → unresolved，剔除；unverifiable 单列）：

| 模型 | correct | wrong | unverifiable（单列） | 准确率 | Wilson 95% CI | 分母 |
|---|---|---|---|---|---|---|
| A-4B | 218 | 2 | 0 | **99.1%** | [96.7, 99.8] | 220 |
| B-9B | 232 | 2 | 2 | **99.2%** | [96.9, 99.8] | 234 |

- 模型间 Fisher 精确检验 **p=1.0**；逐图符号检验 2 wins / 1 loss / 52 ties（**p=1.0**）。
- 只允许写到这一层：**两臂在「写出来的事实是否正确」上几乎相同**；但按协议口径
  （min κ=0.1722 <0.60），**整体结论仍是「样本不足」**，不得写「无显著差异」或「A/B 更好」。
- 准确率**不能**与 binding 覆盖率互相替代：前者衡量「写出来的对不对」，后者衡量
  「事实有没有写进对应子句」（见 §6）。

## 5. 图级幻觉（不可用）

| 模型 | present | judged | 幻觉率 |
|---|---|---|---|
| A-4B | 7 | 55 | 12.7% |
| B-9B | 9 | 60 | 15.0% |

McNemar 配对：b=4 / c=5，**p=1.0**；两人幻觉原始一致仅 **79.1%**，κ=0.1722。
**结论：本轮的幻觉率不可用**（判据未校准、且 60 图 A 臂数据本身含 10 张循环截断图，
「same figure appears again」模板句与截断形态会被不同判读者按不同口径处理）。
不得据此写「哪个模型幻觉更多」。

## 6. 评分校准（自动分 vs 判读排序）

`calibrate --merged 60img/merged.json --from-binding out/g7/round2/binding60.json`：

| 项 | 值 |
|---|---|
| 自动分来源 | `out/g7/round2/binding60.json`（**同版**：G7 第二轮 60 图 / 2 模型的机检覆盖率） |
| 有效单元 n | 115 |
| **Spearman ρ** | **−0.0301** |
| 逐模型 ρ | A-4B −0.1615 / B-9B 0.0941 |
| 翻转率 | 33.3%（相邻对 3，翻转 1） |
| 判定 | **readme_allowed=false：该分不应进 README** |

**这是一个稳定的否定结论**：第一轮 20 图同版 ρ=0.3162（n=39）已不过 0.5；扩到 60 图后
ρ≈0（甚至微负）。即 **binding 覆盖率与判读准确率的排序没有可复现的正相关**，
不能拿「覆盖率」当质量分或 README 卖点。两个量只能并列描述，不能互相替代。

## 7. 三档结论与证据等级

- **三档结论：样本不足（判据不足）** —— min κ=0.1722 <0.60（事实 κ=0.8555 已过，但幻觉 κ 未过）。
  按协议：**不得比较模型优劣**；本轮的允许写法是「事实维度判据已收敛；幻觉维度未校准；
  两臂事实准确率描述性接近，不作模型结论」。
- **事实维度达标声明（本轮协议成果）**：κ=0.8555、分模型均 ≥0.79、分歧 2/458、
  unverifiable 2/4——事实判读在 v2 口径下**可用于下一轮**（下一轮仍需重跑判读包，不复用本轮）。
- **证据等级：B（AI 双读，非人类）**；两名判读者为同一底层模型（deepseek-v4.1-flash），
  独立性弱于「不同模型双读」，更不等于人类判读；`human_packet/` 仍未有人类判读结果。
- **未仲裁**：2 条分歧无第三仲裁（协议允许单列 unresolved），已从准确率分母剔除。

## 8. 局限 / 未覆盖（必须随数字一起读）

1. **60 图判读基于 G7 第二轮产出（循环处置修复前）**：A-4B 60 图里 10 张截断图仍在判读集内
   （caption/IR 有重复循环痕迹）；本轮结论**不直接适用于**修复后的第三轮产出
   （docs/57）。若要评估修复后质量，需要基于 `out/g7/round3` 重跑一轮判读（另开任务）。
2. **每单元 ≤4 claim**（第一轮 ≤9）；κ 只在本轮内解释，不跨轮比较粒度。
3. **幻觉维度不可用**（§5），且没有为幻觉做判例校准；要纳入门禁需另开一轮。
4. **同模型双读**：两名判读者同底层模型，独立性受限；κ 通过只说明「读法自洽」。
5. **无人类判读**：证据等级只能 B；`out/g7/adjudication/60img/human_packet/` 已备好（115 份 md），
   但未交人类判读者。
6. **准确率描述性**：99.1%/99.2% 的分母是「两人一致且已判」的 claim，不含未仲裁分歧；
   CI 宽、p=1.0，只能说明「本批里没有可检测的差异」，不能外推。
7. **样本**：458 claim / 115 单元，分 12 类后每类 n 很小，逐类结论一律不写。

## 9. 复现

```bash
# 1) 判读包（已生成；manifest sha 3ab5d7e7…）
python tools/g7_adjudicate.py packet \
  --json-dir out/g7/round2/json60 --images out/g7/images60.json \
  --max-claims 4 --out out/g7/adjudication/60img
# 2) 两名判读者各自填 judge_a.json / judge_b.json（模板在 60img/templates/）
# 3) 合并（注意：min κ 含幻觉维度 → 退出码 1 属预期）
python tools/g7_adjudicate.py merge \
  --judges out/g7/adjudication/60img/judge_a.json,out/g7/adjudication/60img/judge_b.json \
  --manifest out/g7/adjudication/60img/manifest.json \
  --out out/g7/adjudication/60img
# 4) 同版评分校准（ρ=-0.0301，readme_allowed=false）
python tools/g7_adjudicate.py calibrate \
  --merged out/g7/adjudication/60img/merged.json \
  --from-binding out/g7/round2/binding60.json \
  --out out/g7/adjudication/60img/binding60
```

产物均在 `out/`（不入库）；本文件是唯一入库载体。判读包、判读结果、merged/calibration 的
sha256 见 §1.1。
