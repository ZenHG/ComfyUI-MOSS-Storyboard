### 3.2 「无英文语序」的独立机检（不调用作者判据）

我另写一套规则：挖掉引号内逐字文字与 IR 允许保留的拉丁串（图内文字 / must_keep）
后，检查 ① 英文功能词（the/a/of/with/and/in/on/at/to/for/from/by/is/are…）
② ASCII 标点（`,.;:!?()[]`）。

| 组（4 fixtures × 3 方言 = 12） | 结果 |
|---|---|
| 英文功能词残留 | **0** |
| ASCII 标点混入 | **0** |
| 遮罩引号后的 CJK 占比 | 0.78–0.84（ui-smoke 未遮罩 0.52–0.54 是因为 8 个图内英文文字**逐字保留**，属预期） |
| 角色年龄写成中文 | 全部命中 `N岁`（hero 4 角色 / comic 2 / faceswap 1） |
| 图内文字逐字 | 12/12 全部逐字出现 |
| 作者 `zh_issues()` | 12/12 `[]` |

**判据非空转**（自造输入）：英文输出被 Z01（功能词）+ Z03（ASCII 标点）抓到；
`flumbus` 命中 Z02；`的桌子的` 命中 Z04；`的是一个…` 起手命中 Z05。
**`fact_surface` 不洗白**：把中文输出里的「白色」删掉 → roundtrip 报 `color=white`
丢失；把「画面左/右前景」改成「某处」→ 报 anchor 丢失。

**抽读**（节选，用于人工确认语序，不代替母语审校）：

- qwen-image-2_1 × hero-storyboard：
  「一个28岁的女人坐在画面左前景，黑色长发，扎在脑后，皮肤白皙、光滑，脸型椭圆，
  表情中性，若有所思，略带忧郁，穿着白色高领毛衣（面料柔软、合身），手里拿着一杯柠檬水。」
- krea2 × hero-storyboard（medium-first 方言保留）：

- sdxl × comic-4panel（tag + BREAK）：
  「画面上的文字是「写不下去」，字号偏小，常规字重，…」（分块内词序按中文并列）

## 4. 未覆盖边界（说清本轮没证什么）

   换来的归因值不值，都没有实测；docs/26 §6 #1 已声明，本轮复核的是**接线与判据**。
2. **T5 无母语审校**：机检只证明「没有英文语法的表面特征」+「事实没丢」；
   人读 10 条见 docs/28 §8（已有签收），本轮不重签。
3. **T5 结构化方言不做中文**：Layout JSON / 编辑指令 / 时间线按设计原样输出；
   如果产品上要求这些形态也中文，那是新需求，不是本交付的遗漏。
4. **全量测试口径**：`unittest discover` 559 条中 1 条 error 来自
   `tests/test_core.py`（脚本式测试 import 时 `sys.exit(0)`，该文件未被 T2/T5 改动；
   单独跑通过 313/0）。仓库里还有多个脚本式测试（打印「通过 N / 失败 0」），
   它们不产出 unittest 计数的东西，**不能把 559 当成整个仓库的测试总数**。
5. **公开面**：T2/T5 的 6 个新增/修改文件（`steps.py`、`zh.py`、两个测试、两份文档）
   扫描结果 0 命中（无盘符、无本机用户名、无内部沟通叙事）。
