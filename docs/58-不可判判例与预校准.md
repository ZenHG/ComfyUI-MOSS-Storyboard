## 0. 一句话规则

**只有「图里根本没有呈现相关视觉证据」才允许判 `unverifiable`。**
「不好精确验证 / 需要常识推断 / 只是主观觉得」**都不是**不可判的理由——
只要图中可见信息足以让一个谨慎的判读者做出「大体支持 / 大体反对」的判断，就必须判 `correct` 或 `wrong`。

## 1. 第一轮为什么 κ 低（根因，来自 docs/53）

| 现象 | 数据 | 后果 |
|---|---|---|
| 两人对「可判/不可判」的边界不同 | 51 条分歧里 39 条是 a=unverifiable / b=correct | 原始一致率 85.2% 被类别不平衡抬高，κ 只有 0.4129 |
| 幻觉判读几乎随机 | 39 张图 present 14 / absent 25，κ=0.0377 | 图级幻觉结论在 v2 之前不可用 |
| 年龄 claim 集中触发分歧 | 39 条 a 不可判 / b correct 里绝大多数是「精确定年」 | 需要把「年龄」从「精确值不可核」改成「年龄段可核」 |
| 文字/材质也有反向分歧 | judge_b 在部分文字 claim 上更保守 | 需要逐字/可见表面的硬口径，而不是各自发挥 |

本文的判据就是逐条消解上表（尤其前三条）。

## 2. 判据（v2，按 claim 类型）

判读单位仍是 docs/43 定义的「单元 = 图 × 模型」，每条 claim 给**唯一** verdict：
`correct` / `wrong` / `unverifiable`。整图另判幻觉 present / absent（同一套可见性纪律）。

通用决策树：

```text
claim 的核心要素能否在图中找到视觉证据？
├─ 不能（遮挡/出画/太远/太暗/文字不可辨） → unverifiable
└─ 能
   ├─ 可见证据与 claim 一致（允许 §2.5 的近似） → correct
   └─ 可见证据与 claim 明显不符                  → wrong
```

**禁止**以下理由判 `unverifiable`：
- 「这是主观判断」：主观属性也要按**可见证据**判（见 §2.6/§2.8）；
- 「不可能精确到那个数」：按 §2.3 的容差带判；
- 「我不确定」：不确定时回到「图里到底有没有这个证据」；有证据就判，没证据才不可判；
- 「模型整体看起来行/不行」：只判 claim 所述内容，不做整体印象分。

### 2.1 出现/身份 claim（含 kind 判定）

claim 断言某主体存在/类别为某（人物、物体、图内文字、背景等）：
- 图中可见该主体、类别相符 → `correct`；
- 图中可见该位置/类别明显不是（如在无文字画面上断言有文字） → `wrong`；
- 该主体出画/被完全遮挡 → `unverifiable`。

### 2.2 颜色 / 材质 claim

- 可见表面与 claim 一致（允许 §2.5 近似） → `correct`；
- 可见表面明显不符（写 silver 但可见金色；写木纹但可见金属） → `wrong`；
- 表面不可见/过暗/反光过强/被遮挡 → `unverifiable`。

### 2.3 年龄 claim（硬规则）

**年龄只按「年龄段」判，不按精确岁数判。** 对**单张清晰可辨人脸**：
- 所写年龄落在目测年龄段 **±8 岁**内 → `correct`；
- 落在带外 → `wrong`；
- 群体实体（如 "line of soldiers"）、远景小人脸、脸部被遮挡/背对镜头 → `unverifiable`。

理由：精确年龄在单张图上不可核，但「这个人看起来二十多岁/六十多岁」是可核的；
±8 岁带把「不可核的精确值」转成「可核的区间」，同时不放过明显离群值（如给二十岁的人写 120 岁）。

### 2.4 图内文字 claim（逐字规则，含多串合并）

- 从图中**可辨字符**逐字比对：一致（可忽略装饰符、换行、大小写、明显排版空格） → `correct`；
- 可辨字符与 claim 不符，或 claim 的整串在图中不存在（多个分隔的文字被合并成一串） → `wrong`；
- 文字过小/过糊/大面积被遮挡，无法比对一个以上字符 → `unverifiable`。

局部可辨不等于整体不可判：只要能确认「claim 里的某个关键字符与实际不同」，就判 `wrong`，
不允许用「大概意思对」放过。

### 2.5 「近似」边界（明确写死，避免各判各的）

允许判 `correct` 的近似：同义颜色词（white/cream、grey/gray）、材质家族（painted plaster / painted drywall）、
数量（"a few" vs 具体小数字**不**放行）、措辞顺序差异。
不允许放行：换成不同材质/不同主色/不同类别/不同文字/不同空间关系。

### 2.6 空间 / 数量 claim

主体可见且位置/数量与 claim 一致 → `correct`；明显错位/数量明显不符 → `wrong`；
主体不可见或画面无法判断相对位置 → `unverifiable`。

### 2.7 姿态 / 表情 claim

取 claim 的**核心要素**（朝向、动作、目光方向、大致情绪）：
- 核心要素均与可见姿态一致（修饰词差异不算错） → `correct`；
- 任一核心要素与可见姿态明显冲突（如写「面向左」而人物明显正面） → `wrong`；
- 只能看到局部身体/过暗/背对 → `unverifiable`。

### 2.8 不可见参数与主观媒介 claim

镜头焦段、f 值、光源功率、拍摄设备、精确地理位置、画外身份等**图中不可见参数**：默认 `unverifiable`。
但如果 claim 直接对应可辨的视觉特征（「3d render」对应渲染痕迹/材质质感、「照片」对应摄影质感、
「玻璃反光」可见、画面风格明确）→ 按 §2.1/§2.2 判 `correct`/`wrong`。

### 2.9 图级幻觉（present/absent）

整图判「是否存在与图明显矛盾/图中不存在的事实」。只有能**指出具象反例**（如给磨豆机编年龄、
给无字画面编文字）才判 `present`；没有具象反例判 `absent`。禁止用「感觉可能有幻觉」判 present。

## 3. 判例（8 条，全部来自第一轮 51 条真实分歧）

> 格式：claim 原文 → 第一轮两人判法 → **v2 标准答案** → 依据。
> 这些判例是给判读者的「锚」，判读时遇到同类按同一口径；标准答案是协议约定（Lead 制定），不是模型优劣结论。

### 例 1 · 年龄（年龄段 interior）
- claim：`实体 e1（man） 的年龄为 24 岁`（A-4B · img01，单人特写）
- 第一轮：judge_a `unverifiable` / judge_b `correct`
- **v2：`correct`**
- 依据：图中单张人脸清晰可辨，目测为二十多岁（约 22–29），24 落在 ±8 岁带内。
  「精确 24 不可核」不是不可判的理由（§2.3）。

### 例 2 · 年龄（年龄段 interior，同一图两名不同年龄）
- claim：`实体 e1（man） 的年龄为 72 岁`（B-9B · img04，单人特写）
- 第一轮：judge_a `unverifiable` / judge_b `correct`
- **v2：`correct`**
- 依据：图中为一位头发花白的年长男性，目测约 65–78，72 在带内；
  同一张图上另一模型写 65 岁也判 `correct`——年龄判的是区间不是精确值（§2.3）。

### 例 3 · 年龄（群体实体 → 不可判）
- claim：`实体 e1（line of soldiers） 的年龄为 32 岁`（B-9B · img07，多人互动）
- 第一轮：judge_a `unverifiable` / judge_b `correct`
- **v2：`unverifiable`**
- 依据：claim 主体是「一线士兵」这一群体实体；远处士兵面部不可辨，无单张可判人脸（§2.3 末条）。
  不是「太主观」，而是「没有可判的视觉证据」。

### 例 4 · 图内文字（逐字一致 → correct）
- claim：`图内文字「BULLIC」的逐字内容正确`（A-4B · img17，材质与反光）
- 第一轮：judge_a `correct` / judge_b `unverifiable`
- **v2：`correct`**
- 依据：磨豆机上的椭圆铭牌可辨字符与 claim 一致（§2.4）；不能因为「整体是道具图」而判不可判。

### 例 5 · 图内文字（多串合并 → wrong）
- claim：`图内文字「NOIRMANCETORNE」的逐字内容正确`（B-9B · img20，材质与反光）
- 第一轮：judge_a `wrong` / judge_b `unverifiable`
- **v2：`wrong`**
- 依据：图中水印是**分隔的两串**文字，claim 把它们合并成一串；整串在图中不存在（§2.4）。
  「分不清是不是同一串」不是不可判：可辨字符足够确认它是两串。

### 例 6 · 出现/身份（反光文字也算文字 → correct）
- claim：`画面中存在图内文字（kind=text，label=reflected text）`（B-9B · img11，含图内文字）
- 第一轮：judge_a `correct` / judge_b `unverifiable`
- **v2：`correct`**
- 依据：湿地面反光里可见镜像的招牌文字；claim 的核心是「画面中存在图内文字」，
  反光文字同样满足（§2.1）；「reflected」这一限定也与图中现象相符。

### 例 7 · 材质（可见表面支持 → correct）
- claim：`实体 e2（metallic banner） 的材质为 polished silver or steel with reflective surface`（A-4B · img18，材质与反光）
- 第一轮：judge_a `wrong` / judge_b `correct`
- **v2：`correct`**
- 依据：鹰像爪下的飘带/底座为高反光银灰色金属，可见表面支持「polished silver/steel + reflective」（§2.2、§2.5）。
  判 wrong 需要指出「可见表面明显不符」的反例，而不是因为「它也可以是别的金属」。

### 例 8 · 主观媒介（3d render 有可见渲染痕迹 → correct）
- claim：`画面媒介为 3d render`（B-9B · img18，材质与反光）
- 第一轮：judge_a `correct` / judge_b `unverifiable`
- **v2：`correct`**
- 依据：高光金属质感 + 背景棋盘状渲染边缘痕迹，支持 3D 渲染而非摄影（§2.8 后半条）。
  这条正是「主观判断不是不可判」的典型：可见痕迹能支撑判断时按可见证据判。

## 4. 判读者操作指令（v2）

1. 只读 `out/g7/adjudication/calib2/`（预校准）或 `out/g7/adjudication/60img/`（全量）下的判读包：
   图路径 + caption + IR 实体表 + 候选事实 + 本文判据。**不得读** binding/覆盖率/机检结果/对方判读。
   包内**不得包含**任何一方旧 verdict 或「本轮是争议样本」的标注；若发现泄漏（例如 md/manifest
   里出现 judge_a/judge_b 的判法），立即停止并消息 Lead，不继续判读。
2. 逐单元、逐 claim 填 `correct` / `wrong` / `unverifiable`，**禁止留空、禁止跳过**；
   每条可在 `notes` 写一句「图中看到什么」的依据（建议写，便于复核）。
3. 结果文件必须带 `judge_type: "ai"` 与 `ai_label: "AI 判读，不是人类"`；文件格式按包内空白模板，不改键名。
4. 判读顺序按包内分配（variant_a / variant_b 相反），不要交换包。
5. 遇到本文判据未覆盖的类型：按 §2 决策树推到「可见/不可见」，仍不确定则**消息 Lead**，
   不要自创第三条规则。
6. 判读结论只用于协议校准，不得对外声称「人类判读」或「模型质量真值」。

## 5. 预校准流程与门槛（先小样，后全量）

判读样本：第一轮 39 单元 / 344 claim 中两名判读者** verdict 不一致的 51 条 claim**（最难样本），
由 `calib-packet` 重新打包（含 variant A/B 顺序变体、三份指纹、空白模板）。

```text
两名判读者各自独立判 calib2 包
        ↓
Lead 用现有 merge 算事实 κ（三分类）
        ↓
κ ≥ 0.60 ──→ 进入 60 图全量判读
κ < 0.60 ──→ 修订判例一次（revision 2）→ 同一批重判 → 再 merge
            仍 < 0.60 → 如实记录「判据仍未校准」，60 图只作描述性、不下结论
        ↓
全量结果：历史记录（git 历史）（κ / 准确率 / 幻觉 / ρ；证据等级 B）
```

**为什么用争议子集校准**：一致同意的 claim 对「判据是否收敛」没有信息量；
争议子集是最坏情况。若最坏情况 κ 都 ≥0.6，全量才有意义。
**门槛不达标时的诚实写法**：只能写「样本不足（判据不足）」，不得比较模型优劣（docs/43 §5.2）。

**预校准结果**：见 §8（merge 后回填）。

## 6. 诚实边界（必须随结果一起读）

1. **AI 判读不是人类判读**：两名判读者都是本 harness 的同一底层模型（deepseek-v4.1-flash），
   证据等级仍是 B；κ 通过只说明「同模型两次读法自洽」，不等于人类真值。
2. **本文标准答案是协议约定**：8 条判例由 Lead 制定，目的是让两名判读者共享边界；
   它可能在个别例子上与人类判读不同——校准 κ 只验证「判据是否可复现」，不验证「判据是否真理」。
3. **年龄 ±8 岁、近似材质家族**等阈值是工程判据，不是统计结论；修订需在本文记录 revision。
4. **不可判不等于判错**：`unverifiable` 条目不进准确率分母（docs/43 口径），单列统计；
   若某类 claim 大面积不可判，应讨论「这类 claim 是否适合进判读集」，而不是强行判对错。
5. 第一轮旧结果（docs/53）不因 v2 重算而改变；v2 只用于新一轮。

## 7. 复现

```bash
# 1) 生成预校准包（第一轮 51 条争议 claim）
python tools/g7_adjudicate.py calib-packet \
  --merged out/g7/adjudication/round2/merged.json \
  --json-dir out/g7/round2/json --images out/g7/images.json \
  --out out/g7/adjudication/calib2

# 2) 两名判读者各自填 judge_a.json / judge_b.json（按包内模板）

# 3) 合并并算 κ
python tools/g7_adjudicate.py merge \
  --judges out/g7/adjudication/calib2/judge_a.json,out/g7/adjudication/calib2/judge_b/judge_b.json \
  --manifest out/g7/adjudication/calib2/manifest.json \
  --out out/g7/adjudication/calib2
```

产物在 `out/`（不入库）；本文件是判据与结果的唯一入库载体。
