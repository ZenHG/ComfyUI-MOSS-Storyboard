## 二、必需项

| 项 | 要求 | 依据 | 状态 |
|---|---|---|---|
| **网格声明** | 全局段必须说出「一张画布分成 N 格」这件事 | 三份验证配方 5/5 命中；`core/prompt.py::MULTI_PANEL_PATTERNS` 注释记 2026-10-24 实测「给 1 个 bbox +『恰好 4 个面板』⇒ 输出仍是 4 格」；`docs/_local/internal/08-visual-editor-plan.md` §语义赢 | 【定案】语义驱动；2026-10-27 实测：**删掉它就不再按格分配**（7 臂） |
| **段数 = 格数** | `[PANEL n]` 段数必须等于布局格数（显式计数若写了也必须相等） | C7 对账闸 | 【定案】采样前硬拦 |
| **每段一句主句** | 一段 = 一个画面；主句以景别/取景开头 | 三份验证配方 | 「一段一画面」【定案】；「**必须**景别词开头」未做 A/B【待检验】 |
| **逐格模式的全局段** | 不得残留多格措辞 —— 工具会自动清（`strip_multi_panel_words`） | `core/prompt.py`（2026-10-24 实测） | 【定案】 |
| **图内文字** | 用元素 / `text` 字段给字，不在画面描述里写「要渲染的字」 | `docs/14` §三 | 【定案】 |

## 三、禁项 / 易踩

- **别把布局元语言写进每一格**：网格声明属于全局段；写进 item 会被逐格模式清掉，语义就丢了。
- **别把「英文 / 长散文等价」当已知**：**未验证**。2026-10-27 的 14 次英文跑全部落在
  **缺网格声明**的基线上（那份夹具是"无元语言的对照臂"，不是生产配方），
  **结论一律作废**，不得引用（见 `审计报告/施工/审核-新代码-2026-10-27.md` §十二之补二）。
- **别用 `shot_gradient` / `faces` 判「哪一格落了哪个节拍」**：它们看不见格位落点。
  要判只有两条路 —— 人目检，或先证明新判据能分开已知好/坏样本。

## 四、怎么自检

```bash
# 纯函数：这一稿有没有声明宫格
python -c "import sys; sys.path.insert(0,'.'); from core import prompt as T; \
print(T.grid_declared(open('your.txt',encoding='utf-8').read()))"

# 节点侧：整张 + init=layout 时，未声明会在 report 里给一行 ⚠（只出声，不改写）
COMFYUI_PATH=/path/to/ComfyUI python tools/smoke_nodes.py
```

- `grid_declared` 返回 `None` = 通篇没有 `[PANEL n]`（纯文生图，不判）。
- report 的告警与 C7 闸**互补**：C7 管「段数/格数对不对」，它管「有没有说要分格」。
